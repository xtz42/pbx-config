# Runbook: добавить оператора

Оператор — это строки в базе своего тенанта (ADR 0002), код не меняется.
Пароль проверяет Kamailio (регистратор), Asterisk звонит оператору через SBC.

## 1. Подключиться к базе тенанта

На сервере БД (стенд: `db`, 192.168.57.30), от пользователя postgres:

```bash
sudo -u postgres psql -d bii
```

```sql
SET ROLE bii_owner;
```

`bii` — код тенанта (база и префикс роли совпадают с ним).

## 2. Добавить оператора и включить в очередь

```sql
SELECT pbx_add_operator('1001', 'пароль-не-короче-8-символов', 'Фамилия Имя');
SELECT pbx_add_queue_member('main', '1001');
```

Номер — 2–8 цифр, уникален в пределах тенанта (у разных тенантов номера могут
совпадать: домены регистрации разные). Пароль на стенде — тестовый; в проде
пароли заменит вход через SSO/AD (`docs/placeholders.md`).

Очереди нет? Создать: `SELECT pbx_add_queue('main');` (стратегия `rrmemory`,
20 с на оператора) или `SELECT pbx_add_queue('vip', 'ringall', 15);`.

## 3. Настроить софтфон оператора

| Параметр | Браузер (WebRTC) | Обычный SIP-телефон |
|----------|------------------|---------------------|
| Сервер | `wss://<SBC во внутренней сети>:8443` (стенд: `wss://192.168.57.10:8443`) | прокси `192.168.57.10:5060`, UDP |
| Логин / номер | `1001` | `1001` |
| Домен | домен тенанта из `tenants/<код>.yml` → `operators.sip_domain` (bii: `bii.pbx.test`) | то же |
| Пароль | из шага 2 | из шага 2 |

Регистрация принимается только из внутренней сети (`sbc_operator_networks`
в инвентаре); снаружи — 403.

## 4. Проверить

На SBC — регистрация видна:

```bash
sudo kamcmd ul.lookup location 1001@bii.pbx.test
```

На Asterisk тенанта — оператор в очереди:

```bash
sudo asterisk -rx "queue show main"
```

Тестовый звонок на DID тенанта должен дойти до оператора.

## Убрать оператора

```sql
SELECT pbx_remove_operator('1001');   -- удаляет и из всех очередей
```

## Если не регистрируется

| Симптом | Причина |
|---------|---------|
| 403 на REGISTER | не та сеть (снаружи) или домен не совпадает с тенантом |
| 401 повторяется | неверный пароль; нет оператора в базе; Kamailio не достучался до БД (журнал `journalctl -u kamailio`) |
| WSS не подключается в браузере | не принят сертификат: открыть `https://<SBC>:8443/` и принять |
