# Архитектурные решения (ADR)

Каждое существенное решение — отдельный файл `NNNN-краткое-имя.md`
со статусом, контекстом, решением, альтернативами и последствиями.
Принятые ADR не переписываются: если решение меняется, заводится новый ADR
со ссылкой «Заменяет NNNN», а у старого статус меняется на «Заменён».
