# Звуки

Все `.wav` хранятся в Git LFS (`git lfs install` до клонирования!).
Формат для Asterisk: WAV, 8 кГц, моно, 16 бит PCM.

| Каталог | На сервере | Что |
|---------|-----------|-----|
| `common/<язык>/` | `/var/lib/asterisk/sounds/<язык>/common/` | общие фразы (этап 4) |
| `tenants/<код>/<язык>/` | `/var/lib/asterisk/sounds/<язык>/tenants/<код>/` | приветствия и меню тенанта |

В диалплане: `Playback(tenants/${TENANT}/welcome)` — Asterisk сам выбирает
каталог по языку канала (`CHANNEL(language)`).

## Плейсхолдеры

`tenants/bii/{ru,kk}/welcome.wav` — **временные синтезированные** приветствия
(espeak-ng), только для проверки стенда. Заменить студийными записями.

| Файл | Текст |
|------|-------|
| `tenants/bii/ru/welcome.wav` | «Здравствуйте! Вы позвонили на тестовый стенд контакт-центра. Это временное приветствие.» |
| `tenants/bii/kk/welcome.wav` | «Сәлеметсіз бе! Сіз байланыс орталығының сынақ стендіне қоңырау шалдыңыз. Бұл уақытша сәлемдесу.» |
