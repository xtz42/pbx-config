# Происхождение

Каталог — копия `contrib/ast-db-manage` из исходников **Asterisk 22.12.0**
(`asterisk-22.12.0.tar.gz`, sha256 в `roles/asterisk/defaults/main.yml`).

Отличие от оригинала одно: символьные ссылки `<дерево>/env.py -> ../env.py`
заменены копиями `env.py` — на Windows-клоне (стенд Vagrant) git превращает
ссылки в текстовые файлы. Все `env.py` должны совпадать с корневым. Кроме того, `.gitattributes`
(`eol=lf`) приводит переводы строк к LF (один файл миграции в оригинале с CRLF).
Хуки форматирования pre-commit этот каталог не трогают.

Обновление при переходе на новую версию Asterisk: заменить каталог целиком
из нового tarball, повторить замену ссылок, прогнать миграции на пустой базе (CI).
Применяется ролью `postgresql` (`alembic upgrade head` для деревьев config, cdr, queue_log).
